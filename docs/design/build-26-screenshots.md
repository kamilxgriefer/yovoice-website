# Build 26 screenshot provenance

This record covers the images in `public/screenshots/build-26/`. It lives in
`docs/` rather than beside the images so that it is not served as a public
file.

These images were captured on 2026-09-13 from the running local YO Voice app
preview at source revision `d1c036b7` (`2.0.0 (26)`). The preview used
fixture data and production app widgets, including the real shared Hub
navigation. It did not connect to a live user account or a live Server.

The captures are evidence of the Build 26 interface included in internal
testing. They do not demonstrate that the gated Servers backend or Podcast
recording is active.
